# Optional local music

The historical project used two locally supplied tracks named `Lakeside Arcade.ogg` and `Lakeside Arcade-2.ogg`. These files are **not included** because public redistribution rights have not been confirmed.

The public archive runs without background music. Original procedural sound effects are included. The music controller and its asset-dependent tests are retained as historical source; those two music tests need authorized local copies before they can pass. Do not upload tracks without permission to redistribute them.
