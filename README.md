# One Last Cast / 最后一竿

A fast-paced 2D arcade fishing game where every catch keeps the combo alive. Just one last cast!

## Project direction

All future development is based on **Xcode and native iOS**. The Godot version is retained here as a historical reference, not the active development platform.

- [`legacy/godot/`](legacy/godot/): the completed Godot 0.7.0 prototype, archived on 2026-11-09.
- Native Xcode work is in development separately and is not included in this archival upload.

后续开发只基于 **Xcode 原生 iOS**。已完成的 Godot 0.7.0 版本保留在 `legacy/godot/`，用于回看玩法、素材和测试，不再作为主开发版本。

## Run the archived prototype

Open [`legacy/godot/project.godot`](legacy/godot/project.godot) with Godot 4.7.2, then run the project. See the [archive README](legacy/godot/README.md) for controls, checks and exclusions.

This repository contains source and assets, not an App Store release. Two local music tracks are intentionally omitted because public redistribution rights have not been confirmed. Original sound effects remain available.
